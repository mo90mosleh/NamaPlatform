# NamaPlatform

دموی فارسی و فقط‌خواندنی نما برای شرکت فرضی تولید و فروش تجهیزات «پارس تجهیز آریا».

برای دیدن نسخه آماده، در پوشه `presentation` اجرا کنید:

```sh
python -m http.server 8080 --bind 127.0.0.1 --directory pages
```

نشانی: http://127.0.0.1:8080/

مسیر ارائه: چارت سازمانی ← ثبت سفارش ← برنامه‌ریزی و تولید ← کنترل کیفیت ← تحویل. در صفحه شاخص‌ها «تحویل کامل و به‌موقع» و در OKR هدف متناظر و تاریخچه ثبت پیشرفت را ببینید.

داده مستقل در `presentation/data/nama-demo.sqlite3` قرار دارد. دموی عمومی GitHub Pages از خروجی JSON همین مخزن استفاده می‌کند. برای بازسازی پس از تغییر داده نمونه، در `presentation` اجرا کنید:

```sh
python scripts/seed_demo.py
npm ci
npm run typecheck
npm run build
```

استقرار چندکاربره و ذخیره ویرایش‌ها در سرور به پیکربندی جداگانه نیاز دارند.
